# CiudadConecta

CiudadConecta es una página web para registrar quejas y reportes de los ciudadanos y que puedan ser revisados por el personal municipal.

Es mi proyecto del examen final de **Desarrollo y Diseño Web**, correspondiente a las series I y II.

## ¿Qué permite hacer?

**Portal Ciudadano**
- Registrar una queja o un reporte.
- Escribir la descripción y la ubicación.
- Adjuntar una fotografía.
- Recibir un código de confirmación al enviar la solicitud.

**Panel Municipal**
- Ingresar con contraseña.
- Ver las quejas y reportes registrados.
- Buscar solicitudes y filtrarlas por tipo.
- Consultar la descripción y la fotografía de cada reporte.

## Tecnologías utilizadas

- HTML, CSS y JavaScript para las pantallas.
- Node.js y Express para el backend.
- Firebase Firestore para guardar los reportes.
- Render para publicar la página.

## Ejecutar el proyecto

Se necesita Node.js y configurar las variables de `.env` y la conexión con Firebase. Los datos privados no se incluyen en GitHub.

```bash
npm install
npm start
```

Después se abre `http://localhost:3000` en el navegador.
